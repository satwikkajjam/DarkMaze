# 🔹 Introduction

**Dark Maze** is a first-person 3D survival horror maze game where the player is trapped inside a dark mysterious maze and must escape by collecting hidden trinkets while avoiding enemies, pit holes, and managing stamina.

The maze is nearly invisible without a flashlight, forcing the player to carefully explore the environment. Players must survive using awareness, movement, and strategy.

---

# 🔹 Main Features

- Dark maze environment  
- Flashlight-based exploration  
- Hidden pit holes  
- Enemy AI chasing system  
- Stamina system  
- Wall collision stamina penalty  
- Collectible trinkets  
- Escape objective  
- Horror sound atmosphere  

---

# 🔹 Story Scenario

The player wakes up inside a cursed underground maze with only a weak flashlight.

The maze contains deadly creatures, hidden pit holes, and endless walls. Strange objects are scattered inside the maze. To escape, the player must collect all required trinkets and reach the final gate before stamina runs out.

---

# 🔹 Gameplay Objective

1. Explore the dark maze using flashlight  
2. Collect all trinkets  
3. Avoid enemies  
4. Avoid falling into pit holes  
5. Preserve stamina  
6. Reach exit gate and escape

# 🔹 Special Mechanics

## 🔸 Flashlight System

- Maze is very dark  
- Player depends on flashlight visibility  
- Limited light range increases fear and tension  

## 🔸 Stamina System

- Running consumes stamina  
- Touching maze walls continuously decreases stamina  
- Low stamina reduces movement speed  
- Zero stamina prevents sprinting temporarily  

## 🔸 Pit Holes

- Hidden dark pits placed inside maze  
- Falling into pit causes instant game over or respawn  

## 🔸 Enemy AI

- Enemy patrols maze  
- Detects player nearby  
- Starts chasing player  
- Contact = Game Over
